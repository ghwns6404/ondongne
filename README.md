##  프로젝트 개요

> 개발 기간: 2025.10 ~ 2025.11

**온동네(On동네)** 는  
지역 기반 중고거래와 커뮤니티 기능을 결합한 서비스로,  
AI 기술을 활용해 사용자 경험을 극대화하는 것을 목표로 합니다.

사용자가 상품 사진만 업로드하면  
AI가 **제목, 설명, 카테고리, 가격 범위**를 자동으로 제안하며,  
사용자 행동 데이터를 기반으로 **맞춤형 상품 추천**을 제공합니다.

또한 실시간 채팅과 약속 잡기 기능을 통해  
거래 과정을 자연스럽게 이어주고,  
카카오맵 연동을 통해 **위치 기반 소식 공유**가 가능합니다.

##  프로젝트를 만든 이유

본 프로젝트는 다음과 같은 문제의식에서 출발했습니다.

- **진입장벽 완화**  
  → 상품 등록 과정이 번거롭고 어려운 문제  
  → AI 이미지 분석을 통한 자동 상품 정보 생성

- **개인화된 경험 부족**  
  → 단순 최신순/가격순 정렬의 한계  
  → 사용자 행동 기반 추천 시스템 도입

- **커뮤니티 품질 문제**  
  → 욕설, 비매너 사용자 문제  
  → AI 기반 욕설 필터링으로 건전한 환경 조성

- **실제 사용 가능한 서비스 경험**  
  → 단순 CRUD를 넘어  
  → 실전에서 쓰일 수 있는 구조와 기술 스택 경험

- **지역 단위 서비스의 확장성**  
  → 지역별 중고거래 & 커뮤니티 분리 지원

## ⭐ 핵심 기능

### AI 기반 자동 상품 정보 생성
- 상품 이미지 업로드 시  
- AI가 제목, 설명, 카테고리, 가격 범위 자동 제안

### 하이브리드 추천 시스템
- 카테고리 / 가격 / 키워드 / 인기도 가중치 기반 추천
- 사용자 행동 데이터를 반영한 개인화 추천

### 실시간 채팅 및 약속 관리
- 실시간 채팅을 통한 거래 커뮤니케이션
- 거래 약속 잡기 기능 제공

###  AI 욕설 필터링
- OpenAI 기반 욕설/비속어 필터링
- 커뮤니티 품질 유지 및 사용자 보호

###  위치 기반 소식 공유
- 카카오맵 연동
- 지역별 중고거래 및 커뮤니티 소식 제공

### 게시글 작성시 지도 연동
- 카카오맵 연동을 통해 사진과 위치를 동시에 게시
- 정확한 위치 전달 가능
